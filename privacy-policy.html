MoA 개인정보처리방침

시행일: 2026년 8월 15일 · 문의: uyh00001@gmail.com

MoA(앱 표시명: 중개비서, 이하 “앱”)는 부동산 중개 업무를 위한 일정·매물·고객 정보 관리, 알림, 음성 등록, 수신전화 메모 기능을 제공합니다. 본 방침은 앱이 처리하는 정보와 이용자 권리에 대해 설명합니다.

요약: 일정·고객·전화번호·매물·메모·앱 설정 등 업무 데이터는 사용자 기기에만 저장되며 MoA 운영 서버로 전송하지 않습니다. Google 또는 네이버 로그인은 선택 기능이며, 로그인하지 않아도 기본 업무 기능을 사용할 수 있습니다. 로그인을 이용하면 계정 식별 정보와 로그인 세션이 서버(Firebase Firestore)에 저장됩니다. 앱은 통화 기록(CALL_LOG)과 SMS 내용을 읽지 않습니다.

1. 수집·이용하는 정보

1-1. 업무 데이터(기기 내부 저장)

다음 정보는 앱 기능 제공을 위해 사용자 기기(앱 내부 저장소)에 저장되며, 현재 구현 기준으로 MoA 운영 서버로 전송하지 않습니다.

항목 이용 목적 보관 위치
일정 정보(고객명, 전화번호, 방문일·시간, 장소, 메모, 알림 설정 등) 일정 등록·조회·수정·삭제·알림 기기 내부 저장
고객·전화번호 정보(일정·매물에 함께 저장되는 연락처 정보) 업무 기록, 전화 걸기·문자 앱 실행 보조 기기 내부 저장
매물 정보(주소, 세입자, 메모 등) 매물 등록·조회·수정·삭제 기기 내부 저장
음성 입력으로 변환된 텍스트(원문·인식 결과) 음성으로 일정·매물 등록 기기 내부 저장(텍스트). 음성 파일은 MoA 서버로 전송하지 않음
앱 설정(언어, 기본 알림, 알림음, 수신전화 메모 on/off 등) 앱 환경 유지 기기 내부 저장
수신전화 메모용 로컬 조회 정보(등록된 번호·관련 일정 요약) 등록 번호 수신 시 관련 메모/일정 표시 기기 내부 저장·처리
다른 앱에서 공유한 텍스트(전화번호 포함 가능) 일정 등록 시 번호 입력 보조 기기 내부에서 일시 처리

음성 인식은 기기(및 기기 제조사·OS가 제공하는 음성 인식 서비스)에서 처리됩니다. MoA는 음성 원본 파일을 MoA 운영 서버로 업로드하지 않습니다. OS 음성 인식 서비스의 처리 방식에는 해당 서비스 제공자의 정책이 적용될 수 있습니다.

1-2. 선택 로그인 계정 데이터(서버 저장)

Google 또는 네이버 로그인은 선택 사항입니다. 로그인하지 않아도 일정·매물 등록, 알림, 음성 등록, 수신전화 메모 등 기본 업무 기능을 사용할 수 있습니다. 로그인은 향후 데이터 백업·동기화·기기 변경 시 복원 등을 위한 계정 기반을 위해 제공됩니다. 현재 업무 데이터의 원격 백업·동기화는 제공하지 않습니다.

로그인을 이용하면 아래 정보가 MoA 인증 서버 및 Firebase Firestore에 저장될 수 있습니다.

항목 이용 목적 보관 위치
소셜 로그인 제공자(Google/Naver), 제공자 사용자 식별자 계정 식별, 중복 가입 방지, 로그인 세션 연결 운영자 서버 / Firebase Firestore
이메일(제공·동의한 경우) 계정 프로필 표시 및 계정 관리 운영자 서버 / Firebase Firestore
닉네임 또는 이름(제공·동의한 경우) 계정 프로필 표시 운영자 서버 / Firebase Firestore
프로필 이미지 URL(제공·동의한 경우) 계정 프로필 표시 운영자 서버 / Firebase Firestore
MoA 자체 로그인 세션 정보(세션 토큰 해시, 만료 시각 등) 로그인 상태 유지 및 인증 서버에 세션 기록 저장. 기기의 보안 저장소에는 세션 토큰 보관
네이버 연동 해제용 토큰(해당 시, 암호화 저장) 회원 탈퇴 시 네이버 연동 해제 처리 운영자 서버 / Firebase Firestore(앱에는 장기 저장하지 않음)

Google 계정과 네이버 계정은 이메일이 같아도 자동으로 하나의 계정으로 병합하지 않으며, 각 제공자의 사용자 식별자를 기준으로 관리합니다.

2. 기기 권한

앱이 실제로 선언·사용하는 주요 권한은 다음과 같습니다.

  • 인터넷: 선택 로그인·앱 업데이트 확인 등 네트워크 기능
  • 알림(POST_NOTIFICATIONS): 일정 알림 및 수신전화 메모 알림 표시
  • 마이크(RECORD_AUDIO): 음성으로 일정·매물 등록(사용자가 녹음/음성 입력을 시작할 때)
  • 오디오 설정(MODIFY_AUDIO_SETTINGS): 음성 입력·알림음 재생을 위한 오디오 설정
  • 전화 상태(READ_PHONE_STATE): 수신전화 메모 사용 시 통화 종료 후 알림을 정리하기 위해 사용합니다. 통화 기록(CALL_LOG)은 읽지 않습니다.
  • 연락처(READ_CONTACTS, 선택): 수신전화 메모(Call Screening) 기능과 관련하여 Android가 요구할 수 있는 권한입니다. 앱은 연락처 데이터베이스를 조회해 목록을 수집·저장하거나 서버로 전송하지 않습니다. 수신전화 메모는 앱에 등록된 일정/매물 전화번호와 발신번호를 기기 안에서 대조합니다.
  • 발신자 확인(Call Screening) 역할(선택): 등록된 번호로 전화가 왔을 때 관련 일정·메모를 표시합니다. 통화를 차단하거나 스팸 판별에 사용하지 않습니다.
  • 전체 화면 알림(USE_FULL_SCREEN_INTENT): 잠금 화면에서 일정 알림·수신전화 메모 표시
  • 포그라운드 서비스: 수신전화 메모 등 짧은 백그라운드 처리
  • 진동·깨우기(WAKE_LOCK 등): 알림 표시를 위한 시스템 권한

수신전화 메모, 연락처·전화 상태 권한, Call Screening 역할은 선택 기능입니다. 허용하지 않아도 일정·매물·음성 등록 등 핵심 업무 기능을 사용할 수 있습니다.

3. 읽지 않는 정보

  • 통화 기록(통화목록) — 앱은 READ_CALL_LOG 권한을 사용하지 않습니다.
  • SMS·문자 메시지 내용 — 앱은 READ_SMS 권한을 사용하지 않습니다.
  • 연락처 목록 전체(이름·번호 목록을 수집·저장·전송하지 않음)
  • 위치 정보

4. 수신전화 메모

수신전화 메모는 사용자가 기능을 켠 경우에만 동작합니다. 앱에 저장된 일정·매물의 전화번호와 수신 발신번호를 기기 안에서 대조하고, 일치하면 관련 메모·일정 요약을 알림 또는 오버레이로 표시합니다. 이 과정에서 사용하는 발신번호와 대조 정보는 기기 내부에서 처리되며 MoA 운영 서버로 전송하지 않습니다.

5. 제3자 서비스

앱은 이용자가 입력한 일정·매물·고객 등 업무 데이터를 MoA 운영 서버에 업로드하거나 판매하지 않습니다. 선택 로그인 및 서비스 운영을 위해 다음 외부 서비스를 이용할 수 있습니다.

  • Google: Google 로그인 인증
  • 네이버: 네이버 로그인 인증 및(회원 탈퇴 시) 연동 해제
  • Firebase Firestore(Google): 로그인 계정·세션 등 인증 정보 저장
  • Expo Updates: 앱 업데이트 배포 확인(업무 데이터 전송 목적 아님)

사용자가 전화·문자·메일 앱을 직접 실행하는 경우 해당 OS·앱의 정책이 적용됩니다. 서비스 제공 과정에서 국외 서버에서 계정 정보가 처리될 수 있습니다.

6. 보관 기간 및 파기

  • 로컬 업무 데이터: 사용자가 앱에서 해당 항목을 삭제하거나, 기기 설정에서 앱 데이터를 삭제하거나, 앱을 제거할 때까지 기기에 보관됩니다.
  • 로그인 계정 정보: 서버의 사용자·소셜 계정·세션 등은 회원 탈퇴 시 삭제합니다. 로그인 세션은 로그아웃, 회원 탈퇴 또는 유효기간 만료 시 삭제됩니다.
  • 로그아웃: 서버 세션을 종료하고 기기의 로그인 상태만 제거합니다. 로컬 일정·매물·고객 데이터는 삭제하지 않습니다.
  • 회원 탈퇴: 서버의 MoA 계정, 소셜 계정 연결, 세션, 저장된 연동 토큰(해당 시)을 삭제합니다. Google 계정 자체나 네이버 계정 자체를 삭제하지 않으며, 네이버의 경우 가능하면 연동 해제를 시도합니다. 회원 탈퇴 시에도 이 기기에 저장된 일정·매물·고객 등 업무 데이터는 자동 삭제하지 않습니다.

7. 이용자 권리

  • 앱 내에서 일정·매물 등 업무 데이터를 수정·삭제할 수 있습니다.
  • 설정 > 계정에서 로그인, 로그아웃, 회원 탈퇴를 요청할 수 있습니다.
  • 기기 설정에서 알림·마이크·연락처·전화 상태 권한 및 Call Screening 역할을 언제든 변경·철회할 수 있습니다.

8. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.

9. 방침 변경

법령·기능 변경 시 본 방침을 수정할 수 있으며, 중요한 변경은 앱 또는 본 페이지를 통해 안내합니다.
