MoA 계정 및 데이터 삭제

서비스: MoA · 최종 수정: 2026년 9월 29일 · 문의: uyh00001@gmail.com
공개 URL: https://uyh11225-source.github.io/moa-privacy/account-deletion.html

MoA(이하 “앱”) 서비스 계정은 앱에서 직접 삭제할 수 있습니다. Google 또는 네이버 계정 자체를 삭제하는 것이 아니라, MoA 로그인·동기화·서버에 저장된 계정 정보를 삭제하는 절차입니다.

요약: 회원 탈퇴가 완료되면 MoA 인증 서버(Firebase Firestore 등)의 계정·로그인 정보와 MoA Cloud API에 동기화된 일정·매물 데이터가 삭제됩니다. 기기에 저장된 일정·매물·고객·메모 등 로컬 업무 데이터는 자동으로 삭제되지 않습니다. 무료 사용(체험) 중복 방지를 위한 Trial identity ledger 기록은 별도로 유지될 수 있습니다(아래).

1. 계정을 유지하면서 업무 데이터 삭제

MoA 계정을 삭제하지 않고도 앱에서 일정·매물 등 업무 데이터를 개별 수정·삭제할 수 있습니다. 로그인한 상태에서 삭제한 항목은 클라우드 동기화 시 삭제 시각(tombstone) 정보가 서버에 반영될 수 있습니다. 로그아웃만으로는 로컬·클라우드 업무 데이터가 삭제되지 않습니다.

2. 앱에서 MoA 계정 삭제(회원 탈퇴)

로그인한 상태에서 아래 순서로 회원 탈퇴를 진행할 수 있습니다.

  1. MoA 앱 실행
  2. 설정 탭(또는 설정 화면)으로 이동
  3. 앱 정보 섹션으로 이동
  4. 회원 탈퇴 선택
  5. 안내에 따라 2단계 확인 후 탈퇴 완료

앱은 MoA 인증 서버의 회원 탈퇴 API(POST /auth/delete-account, 로그인 세션 필요)를 호출합니다.

3. 탈퇴 처리 순서(서버)

회원 탈퇴 요청 시 MoA 인증 서버는 대략 다음 순서로 처리합니다.

  1. 로그인 세션으로 MoA Cloud API(DELETE /v1/account-data)에 저장된 해당 계정의 일정·매물 동기화 데이터 삭제를 요청합니다.
  2. 클라우드 삭제가 성공한 경우 Firestore 등 인증 서버의 MoA 사용자 계정, Google/Naver 소셜 연결, 로그인 세션, 네이버 연동 해제용 토큰(네이버 로그인 이용 시)을 삭제합니다. 네이버 연동 해제를 시도할 수 있습니다.
  3. 클라우드 삭제에 실패하면 회원 탈퇴가 완료되지 않을 수 있으며, 앱에 오류 안내가 표시될 수 있습니다.

4. 삭제되는 데이터

회원 탈퇴가 완료되면 MoA 서버에서 다음 정보가 삭제됩니다.

  • MoA 사용자 계정(인증 서버/Firestore)
  • Google 또는 Naver 소셜 계정 연결 정보
  • 로그인 세션
  • 네이버 연동 해제용 토큰(네이버 로그인 이용 시)
  • MoA Cloud API에 저장된 해당 계정의 일정·매물 동기화 데이터

Google 계정 또는 네이버 계정 자체는 삭제되지 않으며, MoA 서비스와의 연결만 해제됩니다.

5. 삭제되지 않거나 보관될 수 있는 데이터

5-1. Trial identity ledger(무료 사용 중복 방지)

동일 Google 또는 네이버 로그인으로 무료 사용을 반복하지 않도록 MoA 인증 서버(Firebase Firestore)에 제한된 Trial 사용 기록이 저장될 수 있습니다. 회원 탈퇴 후에도 이 ledger는 중복 무료 사용 방지 목적으로 삭제하지 않을 수 있습니다.

  • 문서 식별자: 소셜 제공자·제공자 사용자 식별자를 서버 전용 비밀값으로 HMAC-SHA256한 값(원문 provider 사용자 ID·이메일·이름·전화번호·토큰은 ledger 문서 필드에 저장하지 않음)
  • 저장 필드 예: trialConsumed, firstTrialStartedAt, firstTrialEndedAt, createdAt, updatedAt
  • 보관 기간: 중복 무료 사용 방지 목적 달성에 필요한 기간 동안 유지될 수 있으며, 별도의 이용자 요청·법령에 따른 삭제 절차가 없는 한 탈퇴 후에도 유지될 수 있습니다.

5-2. 기기 내부 업무 데이터

회원 탈퇴만으로 자동 삭제되지 않으며 사용자 기기에 남을 수 있는 정보는 다음과 같습니다.

  • 일정, 매물, 고객·연락처, 메모, 앱 설정 등 로컬 업무 데이터
  • 수신전화·공유 이력 등 앱 내부에 저장된 보조 데이터(해당 시)

위 데이터를 삭제하려면 앱에서 항목을 직접 삭제하거나, Android 설정에서 MoA 앱 데이터를 삭제하거나, 앱을 제거할 수 있습니다.

6. 앱에 접근할 수 없는 경우

앱에서 회원 탈퇴가 어렵거나 처리되지 않는 경우, 아래 이메일로 MoA 계정 삭제를 요청할 수 있습니다.

  • 비밀번호, OAuth 토큰, 인증 코드 등 민감한 인증 정보를 이메일로 요구하지 않습니다.

7. 관련 안내
